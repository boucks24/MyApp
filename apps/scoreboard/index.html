Scores come from ESPN's public feeds, fetched directly from your browser (this page has no server of its own). Those feeds are unofficial, undocumented, and can change or go down without notice — if a section stops loading, that's ESPN's endpoint, not something saved on this device. Tennis is filtered client-side to Grand Slam, Masters/1000 and tour-500 events by tournament name (list: TENNIS_500PLUS_KEYWORDS) and then to matches with at least one player ranked top 50 (top 100 if Australian) using ESPN's separate, even-less-documented rankings API (fetchTennisRankings()). Both of those tennis filters fail open: if the tier or ranking filter would have matched nothing despite matches actually being on, it shows everything unfiltered at that stage instead and says so inline — a filter matching zero real matches is treated as the filter being broken, not the schedule being empty. Rugby union covers Super Rugby Pacific (Australian Super Rugby teams) and the Rugby Championship (Wallabies internationals) by numeric ESPN league ID. Cricket uses a different, cross-domain "personalised header" endpoint filtered to matches involving Australia — Big Bash/WBBL aren't wired up, their league ID wasn't verifiable when this was built. Review each season and adjust SOURCES/TENNIS_500PLUS_KEYWORDS as calendars and endpoints shift.
