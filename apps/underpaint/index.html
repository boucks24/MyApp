Underpaint

A small bench of tools for painters: mix paint colours the way pigments actually behave, pull a working palette from a reference photo, and simplify a photo into flat colour shapes for a study.

Colour mixer

Add or remove paints and set how many parts of each go into the mix. Mixing happens in a pigment-like colour space, so blue and yellow make green instead of grey mud.

#000000
rgb(0, 0, 0)

This uses an RYB-style approximation of subtractive paint mixing rather than a scientific pigment model (which would need each paint's real reflectance data). Treat the result as a starting point on the palette, not a guarantee — always test small.

Target colour

Pick a colour to aim for, then either practise mixing it yourself or let Underpaint work out a recipe from your current paints.

Image to palette

Drop in a reference photo to pull out the colours you'd need to mix for it. Click any swatch to copy its hex code.

Simplify to vector

Flattens a photo into a small number of solid colour shapes and traces them into an SVG, with a colour-swatch legend added underneath — handy for a value study, a stencil, or a simplified block-in. Updates live as you adjust the sliders.
