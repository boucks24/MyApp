Target colour

This uses a simplified Kubelka-Munk pigment model — the same absorption/scattering theory behind tools like Mixbox — rather than each paint's exact measured reflectance data, so treat the result as a strong starting point, not a guarantee — always test small. Oil is mixed at full strength; gouache dries a little lighter and flatter as its chalk fillers set; watercolour is modelled as a transparent wash diluted with paper-white rather than mixed with white paint. Colour names are estimated from the nearest common colour, not an exact match.
