Pick as many as you like. Burst shots work well

2. Order by body position

Runs pose detection (TensorFlow.js MoveNet, the same model Shot Finder's ball/swing tracking uses) on each photo, then chains them so similar limb angles and player size sit next to each other, aiming for a sequence that reads as one continuous, fluid motion rather than a random slideshow. Works best with one clear player per photo; a 2D pose model can't tell front from back, so treat the order as a strong starting point, not gospel.

3. Ordered sequence

Photos with no confident pose, or whose pose didn't match the rest of the batch, are dropped automatically. See the status above for how many. Use the arrows to nudge the remaining order left/right. When the video is built, each photo is rotated, scaled and shifted so its pose lands in the same spot as the last one, because matching body position takes priority over keeping the whole frame in view.
